# Quickstart & Validation: 질문별 답변 공개 진행

이 문서는 구현 뒤 격리한 테스트 행사에서 네 질문의 공개 순서와 권한 경계를 확인하는 기준이다.
운영 답변이나 운영 발표 상태를 테스트에 사용하지 않는다.

## Prerequisites

- Node.js 22, Docker와 분리된 PostgreSQL 테스트 데이터베이스가 준비돼 있어야 한다.
- 기존 참가자 등록, 관리자 로그인과 답변 저장 기능이 동작해야 한다.
- 테스트 행사는 고정 질문 네 개와 관리자 한 명, 참가자 네 명을 가진다.

## Setup and Automated Gates

```bash
npm ci
npm run typecheck
npm run lint
npm test
TEST_DATABASE_URL=<isolated-url> DATABASE_URL=<isolated-url> npm run test:integration
npm run build
npm run test:e2e
```

기대 결과: 마이그레이션과 시드가 네 질문을 정확한 순서로 만들고, 단위·통합·브라우저 테스트와
기존 참가자·관리자 회귀 테스트가 모두 통과한다.

## Test Data

각 질문에 짧은 한글 답변, 줄바꿈·이모지 답변, URL이 포함된 답변을 준비한다. 첫 질문에는
답변 3개, 두 번째에는 2개, 세 번째에는 1개, 네 번째에는 0개를 둔다. 긴 표시 검증에는
1,000자 경계 답변을 추가한다.

## Scenario 1: 질문 순서와 참가자 입력 경계

1. 행사 시작 전에 참가자와 진행자 화면을 연다.
2. 참가자 화면에서 네 질문을 모두 저장한다.
3. 첫 질문을 완료해 두 번째 질문으로 전환하고 참가자 화면을 다시 확인한다.

기대 결과:

- 참가자는 행사 전에 네 질문을 모두 읽고 각 질문의 답변을 저장할 수 있다.
- 아직 발표하지 않은 질문의 답변과 작성자 정보는 프로젝터 응답에 없다.
- 행사 시작 뒤 참가자는 답변을 새로 쓰거나 수정할 수 없다.

## Scenario 2: 질문 안의 답변·작성자 공개

1. 진행자가 첫 질문을 시작한다.
2. 다음 답변 공개를 선택하고 프로젝터 화면을 확인한다.
3. 작성자 공개를 선택한 뒤 같은 화면을 확인한다.
4. 다음 답변으로 이동을 시도한다.

기대 결과:

- 답변 공개 직후 프로젝터 응답에는 `author`가 없다.
- 작성자 공개 뒤에만 정확한 닉네임과 캐릭터가 나타난다.
- 작성자를 공개하기 전에는 다음 답변으로 이동할 수 없다.
- 작성자 공개를 마친 답변만 완료 수에 포함된다.

## Scenario 3: 다음 질문 전환과 빈 질문

1. 첫 질문의 모든 답변을 완료한다.
2. 두 번째 질문으로 전환한다.
3. 미완료 답변이 남은 상태에서 세 번째 질문 전환을 시도한다.
4. 네 번째의 빈 질문까지 진행하고, 참가자 기록 화면을 연다.

기대 결과:

- 현재 질문을 끝내기 전에는 다음 질문으로 넘어가지 못하고 남은 수가 보인다.
- 질문은 1→2→3→4 순서로만 시작된다.
- 답변 0개 질문은 빈 상태를 확인한 뒤 다음 단계 또는 전체 완료로 넘어갈 수 있다.
- 마지막 질문 뒤 화면은 전체 완료 상태가 되고, 로그인한 참가자는 질문별 모든 답변과 작성자를 볼 수 있다.

## Scenario 4: 영속성·동시성·권한

1. 답변 하나를 익명으로 공개한 상태와 작성자까지 공개한 상태에서 각각 새로고침한다.
2. 앱을 재시작하고 질문 위치·답변 상태를 다시 확인한다.
3. 두 관리자 창에서 다음 답변 또는 다음 질문 명령을 거의 동시에 보낸다.
4. 로그아웃·참가자 세션으로 세 관리자 API와 화면에 접근한다.

기대 결과:

- 현재 질문, 답변, 작성자 공개 여부와 질문별 완료 수가 복구된다.
- 동시 요청은 질문 건너뛰기·이중 선택·작성자 공개 전 전환 없이 하나의 순서로 완료된다.
- 비관리자는 비공개 답변, 진행 상태와 프로젝터 화면을 한 건도 받지 못한다.
- 모든 민감 응답은 `no-store, private`이며 쓰기 요청은 Origin·CSRF 검증 없이는 거부된다.

## Scenario 5: 접근성 및 화면 복구

1. 1,366×768 프로젝터에서 긴 답변, URL, 이모지를 차례로 표시한다.
2. 키보드만으로 질문 시작, 답변 공개, 작성자 공개, 다음 질문 전환을 한다.
3. 프로젝터 네트워크를 끊었다가 다시 연결한다.

기대 결과:

- 본문이 겹치거나 잘리지 않고 끝까지 읽을 수 있다.
- 주요 동작에 텍스트 라벨·포커스·상태 안내가 있다.
- 연결이 끊긴 동안 마지막 정상 슬라이드를 유지하고, 복구 뒤 5초 안에 최신 revision으로 맞춘다.
